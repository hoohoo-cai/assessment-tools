#  README

单文件网页工具：加载交通录像，播放/暂停，在当前画面时刻添加文字备注，点击列表中的备注即可跳回对应时刻。零依赖、离线可用。

---

## 一、运行环境

| 项目    | 要求                                                      |
| ----- | ------------------------------------------------------- |
| 操作系统  | Windows 10/11、macOS 12+、主流 Linux 桌面均可                   |
| 浏览器   | Microsoft Edge 或 Google Chrome（Chromium 内核，建议 120 以上版本） |
| 运行时依赖 | **无**。不需要 Python、Node.js、npm，不装任何库                      |
| 网络    | 不需要联网，纯本地运行                                             |
| 服务器   | 不需要，双击 `file://` 直接打开                                   |
| 浏览器设置 | 需允许 localStorage（默认允许；无痕模式会导致备注无法保存）                    |

> 唯一可选外部工具是 `ffmpeg`，仅在录像编码浏览器不支持、需要转码时用到（见第四节），正常运行不需要。

---

## 二、安装 / 启动步骤 


1. ** 如何载入视频：将素材视频放在 `index.html` 同目录，文件名 `京津道路车流录像.mp4
2. **放置文件**：把 `index.html` 与录像放在同一个文件夹下，录像命名为 `京津道路车流.mp4`：
   ```text
   录像标记工具/
   ├── index.html
   └── 京津道路车流.mp4
   ```
3. **启动**：双击 `index.html`，用 Edge 或 Chrome 打开，页面出现播放器即成功。

**没有放录像 / 文件名不一致时**：点击页面上的「载入录像」按钮，选择任意本地 MP4 即可，无需改代码、无需改目录。

## 三、输入输出

### 输入

| 输入项      | 说明                                                       |
| -------- | -------------------------------------------------------- |
| 录像文件     | 浏览器可解码的 MP4（H.264 视频 + AAC 音频）。自动加载同目录默认文件，或通过「载入录像」按钮选择 |
| 备注文字     | 用户在输入框填写的一句话（纯文本）                                        |
| 备注时间点    | 自动取保存瞬间的 `video.currentTime`，用户无需输入                      |
| 导入文件（可选） | 本工具导出的 `.json` 备份文件                                      |

### 输出

| 输出项      | 说明                                                  |
| -------- | --------------------------------------------------- |
| 备注列表     | 按时间升序显示「mm:ss.s + 备注文字 + 删除按钮」，连续添加互不覆盖             |
| 持久化数据    | 写入浏览器 localStorage，key 按「视频文件名 + 文件大小」区分，刷新、关闭重开不丢失 |
| 视频跳转     | 点击备注后播放器定位到对应时刻；跳转前播放则继续播放，暂停则保持暂停                  |
| 导出文件（可选） | 备注备份 `.json`，含视频文件名与全部备注，可导入恢复                      |

---

## 四、已知限制

1. **仅支持浏览器原生可解码的 MP4**（H.264 + AAC）。录像若为 H.265/HEVC 编码会黑屏或只有声音，需先转码，工具本身不做转码。转码命令：
   ```bash
   ffmpeg -i "原录像.mp4" -c:v libx264 -preset medium -crf 23 -c:a aac -b:a 128k "demo_h264.mp4"
   ```
2. **无法自动记住上次选择的录像**。受浏览器安全限制，刷新后需重新点「载入录像」；备注不会丢，重新选中同一文件（按文件名 + 大小识别）后自动恢复。
3. **备注存在本机浏览器**，不跨设备、不跨浏览器同步；清理浏览器数据会丢失，演示前建议先「导出 JSON」备份。
4. **跳转精度约 0.1 秒**。浏览器按关键帧定位，无法保证帧级精确，属播放器特性，不影响使用。
5. **未支持**：框选/截图标注、多人协作、备注分类、倍速播放。
6. **未在 Safari 与移动端浏览器上测试**，建议使用桌面版 Edge / Chrome。
